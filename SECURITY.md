# Security Policy

## Supported releases

Security fixes are targeted at the latest published Apex Auto-Clicker release.
Until the first release is published, report vulnerabilities against the
current `master` branch.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues, pull
requests, discussions, screenshots, or logs.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Open **Advisories**.
3. Choose **Report a vulnerability** and submit the report privately.

If the private reporting action is not available, contact the repository owner
through GitHub to arrange a private disclosure channel before sharing technical
details.

Please include the affected release or commit, operating system, reproduction
steps, impact, and any suggested mitigation. Avoid including live credentials,
personal data, or unrelated application content.

We will acknowledge reports when practical, investigate the issue, and
coordinate any fix and public disclosure with the reporter.
